I just wrapped up my contribution to typeshed, the official repository that provides type annotations for Python's standard library and popular third-party libraries. I finished incomplete type annotations for 10 functions across 3 modules of algorithms from the network analysis library, networkx. Type annotations tell Python tools what kind of data each function expects and returns, which can be helpful when trying to catch coding errors early, and on a team where self-documenting code is important. To do this, I dug through the networkx source code to determine the correct return type for each function, updated typeshed to match, and then verified the correct type annotation.
